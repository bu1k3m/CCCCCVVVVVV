# ORG CV

A clean, professional single-page CV/resume website for Chibuikem Okoli, a Junior Frontend Developer. This project showcases a responsive resume design built with HTML, CSS, and semantic markup.

## Project Overview

This is a static single-page CV that displays:

- **Contact Information** - Location, phone, and email
- **Skills** - Frontend development technologies and soft skills
- **Education** - Academic background and coursework
- **Experience** - Professional and freelance work experience
- **Internet Presence** - Links to LinkedIn and GitHub profiles

The design is responsive and works well on both desktop and mobile devices, with a professional dark border styling and green accent colors.

## How to Run Locally

1. **Clone the repository** (or download the files):

   ```bash
   git clone <repository-url>
   cd ORG\ CV
   ```

2. **Open in your browser**:
   - Simply open the `index.html` file in your web browser
   - You can double-click the file or right-click and select "Open with" > your preferred browser

3. **Optional - Use a local server** (for testing):
   - If you have Python installed:
     ```bash
     python -m http.server 8000
     ```
   - Then visit `http://localhost:8000` in your browser

4. **View your CV** - The resume will display in a centered, printable format
